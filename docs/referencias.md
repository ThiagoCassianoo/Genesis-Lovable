# Referências visuais fixas

Lista curada pro `creative-agent` cruzar toda proposta: "isso é um
momento 3D-uau, um momento scroll-narrativo, ou um momento
luxo-sóbrio?" — cada categoria resolve um problema diferente, não
misturar tudo no mesmo projeto.

## 3D/WebGL como protagonista
Efeito "uau" imediato — 3D interativo com propósito, nunca decorativo.
- **Lusion.co** — referência máxima de 3D interativo com propósito narrativo
- **Basement.studio** — 3D + humor + identidade forte
- **Cuberto.com** — motion + 3D, portfólio de agência premium
- **Active Theory (activetheory.net)** — experiências imersivas de altíssimo nível

## Scroll storytelling / GSAP em timeline
A jornada que prende do primeiro ao último scroll.
- **Rauno.me** — micro-interação minimalista e cirúrgica
- **Locomotive.ca** — criador do padrão de smooth scroll que inspirou o Lenis

## Alto-ticket / luxo sóbrio
Pra quando "sensacional" precisa ser elegante, não barulhento — mais
perto do público de igreja/ministério.
- **Stripe.com** — altíssimo padrão com pouquíssimo exagero
- **Linear.app** — precisão visual, motion contido e caro
- **Resend.com** — minimalismo memorável, pouca poluição visual

## Curadoria contínua / vitrine de componentes
- **21st.dev** — garimpar padrão de componente pronto
- **Awwwards.com** (Site of the Day) — buscar referência nova quando o
  diretor pedir "algo que ninguém viu ainda"
- **Land-book.com** — inspiração por categoria/indústria
- **Dribbble.com** — inspiração visual, nunca copiar 1:1, só extrair princípio

## Como usar
1. Antes de propor qualquer direção criativa, o `creative-agent` cruza
   a ideia com pelo menos uma categoria acima.
2. Esta lista é fixa mas viva — o diretor adiciona/substitui com print
   ou link a cada projeto novo.
3. Nunca copiar layout 1:1 — extrair o princípio (mecanismo de
   atenção, técnica de motion, hierarquia), não o pixel.
