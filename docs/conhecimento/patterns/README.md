# Banco de padrões vencedores

Cada efeito (3D, scroll, micro-interação) que funcionar bem num projeto
real vira um arquivo aqui — descrição do efeito, biblioteca usada,
contexto onde funcionou, e por que funcionou (qual princípio de
psicologia/atenção ele explora). Evita reinventar a cada projeto novo
e eleva a régua de qualidade com o tempo.

## Como registrar um padrão novo
Depois que o `reviewer-agent` aprovar uma etapa com nota alta, o
diretor decide se o efeito vira padrão catalogado. Formato sugerido
por arquivo (`docs/conhecimento/patterns/nome-do-efeito.md`):

```
# Nome do efeito
Biblioteca: [R3F / GSAP / Lenis / Framer Motion]
Projeto de origem: [nome do projeto]
Princípio aplicado: [ex.: Von Restorff, Zeigarnik]
Descrição: [2-3 frases do que o efeito faz]
Quando reusar: [tipo de seção/contexto onde funciona]
```

Nenhum padrão é catalogado automaticamente — é curadoria do diretor,
não geração automática dos agentes.
